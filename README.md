Static, responsive, recruiter-friendly portfolio showcasing practical cybersecurity, IT and independent software projects.

- Practical cybersecurity labs and technical documentation

- Security operations and SOC skills currently in development

- Real-world IT troubleshooting, system recovery and security support experience

Repository: https://github.com/iamskottk/Clinic-Communication-System
