# Kabo Sekoto — Cybersecurity Portfolio

Static, responsive, recruiter-friendly cybersecurity portfolio for GitHub Pages.

## Files
- `index.html` — structure and content
- `style.css` — dark responsive design
- `script.js` — project cards, filters and detail modal

## Before publishing
- Replace `YOUR_EMAIL@example.com` with your real email.
- Add your TryHackMe profile URL.
- Add Week 2/Week 3 GitHub, write-up, screenshot and demo URLs when ready.
- Add certificate URLs.
- Add verified CTF, hackathon and community records when available.

## GitHub Pages
Recommended repository name: `KaboSekoto.github.io`.
Upload the website files to the repository root, then enable Pages from the `main` branch and `/root` folder.
